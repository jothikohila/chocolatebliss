CHOCO BLISS — how to run
1. Right-click CHOCO_BLISS_CORRECTED.zip > Extract All.
2. Open the choco_bliss folder in VS Code (File > Open Folder).
3. Install the "Live Server" extension (Ritwick Dey).
4. Right-click index.html > "Open with Live Server".
Images: live Unsplash photos load on top of local illustrations in assets/img/.
If a photo is unavailable, the local illustration shows instead — never a broken icon.
To use your own photos, replace the URLs in the data-srcs attributes (index.html) and the srcs lists (script.js).
Checkout and the contact form are demos: no payment or email backend is connected.
